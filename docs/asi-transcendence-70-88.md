AegisFleet implements these requests as bounded, deterministic, testable contracts. They are engineering abstractions, not claims to reproduce consciousness, ASI, proprietary systems, quantum advantage, formal completeness, or biological cognition.

## RSI safety contract

No capability in this layer may autonomously modify source code, credentials, policies, phone authorization, production infrastructure, or historical audit records. The existing RSI protocol remains:

`OBSERVE → PROFILE → HYPOTHESIS → GENERATE → AIR-GAPPED SANDBOX → RED TEAM → FORMAL GATE → BENCHMARK → SHADOW → HUMAN/POLICY APPROVAL → ATOMIC RELEASE → ROLLBACK`

Quantum, FPGA, ZK, TDA and active-inference modules are integration boundaries or deterministic research abstractions until a separately authorized implementation is supplied and verified.
